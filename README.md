# validation-app-practice

## 概要
COACHTECH 教材 Tutorial 9-6「バリデーション ハンズオン演習」で作成した成果物です。
バリデーションを使ってユーザー登録フォームに本来想定されていない入力への対処が可能なウェブページの作成を行った

## 使用技術
- PHP 8.x
- Laravel 10.x
- FormRequest / バリデーションルール
-コーチテックのAI
-ジェミニ

## 学んだこと
- バリデーションには｜をつかって羅列する方法とクロージャ―を使って配列形式で記述する2種類があると学んだ。｜を使用した羅列のほうが直感的で自分の中では理解しやすかった
- フォームリクエストを使用することでコントローラーの太りを減らせると学んだが、実際文字量として実感できなかったので復習が必要だと考えた
- エラーメッセージの挿入箇所が初めはあまり理解できていなかったが、messagesに追加するだけで良いと知った

## 動作確認
実際ページを開いて情報入力をしてみて、エラーメッセージが出るかを確認した
無入力だった場合も同じようなエラーメッセージが出るか確認した
